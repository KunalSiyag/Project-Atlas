## Vision
Atlas enables teams to build production AI agents with modular orchestration, reliable evaluation, deep observability, and replaceable provider integrations.

## Non-Goals
- Atlas is not a single-purpose chatbot application.
- Atlas is not tied to one model vendor, vector database, cloud provider, or UI framework.
- Atlas does not prioritize demos over maintainable production architecture.

## Success Criteria
- Teams can reason about each service from local documentation.
- Provider changes are handled through configuration and adapters where practical.
- Agent executions are observable, testable, and auditable.
