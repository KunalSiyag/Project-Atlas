# RFC Process

## Purpose
Define how large Atlas features are proposed and accepted.

## Scope
Applies to major features, cross-service behavior, new service creation, and externally visible contracts.

## Dependencies
- [RFC Template](./0000-template.md)
- [ADR Index](../adr/README.md)

## Owner
Atlas Product Engineering

## Status
Accepted

## Last Updated
2026-08-03

## Related Documents
- [Engineering Principles](../engineering/PRINCIPLES.md)

## Process
1. Create an RFC from the template.
2. Document goals, non-goals, requirements, design, risks, and acceptance criteria.
3. Review trade-offs and open questions.
4. Mark the RFC Accepted before implementation begins.
5. Create ADRs for architectural decisions that arise from the RFC.
