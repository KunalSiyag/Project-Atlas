## Required Metadata
Every durable document must include:
- Purpose
- Scope
- Dependencies
- Owner
- Status
- Last Updated
- Related Documents

## Status Values
Use one of these status values unless a document defines a narrower workflow:
- Draft
- Proposed
- Accepted
- Deprecated
- Superseded
- Bootstrap

## Writing Guidance
- Prefer small focused documents.
- Link to related documents instead of duplicating large sections.
- Record assumptions explicitly.
- Separate product intent from technical implementation.
- Use concrete acceptance criteria for planned work.
